## 📝 문서 작성 규칙

`_템플릿.md`를 복사해서 사용. 아래 **4개 섹션만** 작성.

1. **문제** — 무엇이 문제였고 어떤 증상이 있었는가
2. **목적** — 무엇을 어디까지 구현/수정할 것인가
3. **수정 / 생성 파일** — 어떤 파일을 수정/생성했고 각 파일의 역할과 변경 내용
4. **수정 전 / 후** — Before/After 코드 비교
