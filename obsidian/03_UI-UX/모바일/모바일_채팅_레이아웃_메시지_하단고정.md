# 모바일 채팅 레이아웃 — 메시지 하단 고정 & iOS 스크롤 버그 수정

- **작업일**: 2026-02-24
- **분류**: `03_UI-UX / 모바일`

---

## 문제

### 증상

모바일 웹 채팅 페이지에서 두 가지 문제가 동시에 발생.

1. **채팅 메시지가 화면에 안 보임** — 키보드를 올리면 메시지 영역이 뷰포트 위로 밀려나감
2. **최신 메시지가 하단에 없음** — 메시지가 적을 때 상단에 붙어서 빈 공간이 하단에 생김

### 원인 1 — iOS document 스크롤 (메시지 사라짐)

```
[뷰포트 위]
  [AppBar]          ← 화면 밖으로 밀림
  [메시지 영역]     ← 화면 밖으로 밀림 (안 보임)
[뷰포트 경계]
  [입력창]          ← iOS가 여기를 화면 안으로 스크롤
  [키보드]
```

input에 포커스가 생기면 iOS Safari가 **document 자체를 스크롤**해서 input을 화면 안으로 올린다.
outer Box가 `height: var(--app-height)` + 일반 흐름(static)으로 배치되어 있었기 때문에,
document 스크롤 시 메시지 영역 전체가 뷰포트 위로 사라짐.

### 원인 2 — 메시지 상단 정렬 (최신 메시지 미하단)

```
[메시지 영역]
  안녕하세요      ← 메시지 상단 배치
  반갑습니다
  [빈 공간]       ← 최신 메시지 아래에 빈 공간
[입력창]
```

메시지 영역이 `flex: 1`로 공간을 채우지만 내부 메시지들이 위에서 쌓이는 구조.
메시지가 적을 때 최신 메시지가 상단에 있어 UX가 WhatsApp/카카오톡과 다름.

## 해결 방법

### 해결 1 — outer container `position: fixed` 전환

iOS Safari에서 `position: fixed` 요소는 **visual viewport 기준**으로 배치된다.
즉, 키보드가 올라와도 `bottom: 0`은 항상 키보드 바로 위에 고정됨.
document가 스크롤되어도 fixed 요소 자체는 움직이지 않음.

```
Android Chrome (interactive-widget=resizes-content):
  → viewport 자체가 줄어들어 fixed bottom:0 = 키보드 상단 ✓

iOS Safari:
  → fixed 요소가 visual viewport 기준 → bottom:0 = 키보드 상단 ✓
```

#### 변경 전 (`ChatPage.tsx`)
```tsx
<Box sx={{
  display: 'flex',
  flexDirection: { xs: 'column', md: 'row' },
  height: { xs: 'var(--app-height)', md: '100vh' },  // ← JS 변수에 의존, 스크롤에 취약
  overflow: 'hidden',
  width: '100%',
}}>
```

#### 변경 후 (`ChatPage.tsx`)
```tsx
<Box sx={{
  display: 'flex',
  flexDirection: { xs: 'column', md: 'row' },
  // Mobile: position fixed → iOS document scroll로 인한 뷰포트 이탈 방지
  position: { xs: 'fixed', md: 'relative' },
  top: { xs: 0, md: 'auto' },
  left: { xs: 0, md: 'auto' },
  right: { xs: 0, md: 'auto' },
  bottom: { xs: 0, md: 'auto' },
  height: { xs: 'auto', md: '100vh' },  // mobile은 top/bottom으로 높이 결정
  width: { xs: 'auto', md: '100%' },
  overflow: 'hidden',
}}>
```

내부 content Box도 `height` 수정:
```tsx
// 변경 전
height: { xs: 'var(--app-height)', md: '100vh' }

// 변경 후
height: { xs: '100%', md: '100vh' }  // outer가 fixed이므로 100% = 전체 viewport
```

### 해결 2 — flex spacer 패턴으로 메시지 하단 고정

메시지 영역 컨테이너를 `display: flex + flexDirection: column`으로 변경하고,
메시지 목록 **앞에** `flex: 1` spacer를 배치.

```
[메시지 영역 컨테이너] ← overflow: auto, display:flex, flex-direction:column
  [spacer flex:1]    ← 빈 공간이 위를 채움
  안녕하세요         ← 메시지들이 하단에 위치
  반갑습니다
  [messagesEndRef]
[입력창]
```

| 상황 | spacer 동작 | 결과 |
|------|------------|------|
| 메시지 적음 (no overflow) | spacer가 빈 공간 채움 | 메시지 하단 고정 ✓ |
| 메시지 많음 (overflow) | spacer가 0으로 수축, 컨테이너 스크롤 | `scrollIntoView`로 최신 메시지 노출 ✓ |

#### 변경 후 (`ChatArea.tsx`)
```tsx
{/* 메시지 영역 */}
<Box
  sx={{
    flex: 1,
    minHeight: 0,       // flex item이 content 크기 아래로 줄어들 수 있게
    overflow: 'auto',
    display: 'flex',    // ← 추가
    flexDirection: 'column',  // ← 추가
    p: { xs: 2, md: 3 },
    bgcolor: colorScheme.backgroundColor,
    // ... scrollbar 스타일
  }}
>
  {messages.length === 0 && !isStreaming ? (
    <Box sx={{
      flex: 1,          // ← height:'100%' 대신 flex:1 사용
      display: 'flex',
      alignItems: 'center',
      justifyContent: 'center',
      // ...
    }}>
      {/* 빈 화면 안내 메시지 */}
    </Box>
  ) : (
    <>
      {/* 핵심: spacer가 위쪽 빈 공간을 채워 메시지를 하단으로 밀어냄 */}
      <Box sx={{ flex: 1, minHeight: 0 }} />

      {messages.map((msg, index) => (
        // ... 메시지 버블
      ))}

      {isStreaming && (/* 스트리밍 메시지 */)}

      <Box ref={messagesEndRef} sx={{ height: 1 }} />
    </>
  )}
</Box>
```

### 해결 3 — 입력 영역 safe-area-bottom 처리

outer container가 `bottom: 0`으로 화면 절대 하단까지 내려가므로,
iPhone 홈 인디케이터 영역과 입력창이 겹칠 수 있음.

```tsx
{/* 입력 영역 */}
<Box
  sx={{
    flexShrink: 0,
    // 키보드 닫힘: --effective-sab = env(safe-area-inset-bottom) → 홈 인디케이터 위로 이동
    // 키보드 열림: --effective-sab = 0px → 키보드가 홈 인디케이터를 가리므로 여백 불필요
    pb: isMobile ? 'var(--effective-sab)' : 0,
  }}
>
  <ChatInputArea />
</Box>
```

`--effective-sab`는 `index.html` JS에서 동적으로 설정 (키보드 감지):
```js
document.documentElement.style.setProperty(
  '--effective-sab',
  isKeyboardOpen ? '0px' : 'env(safe-area-inset-bottom)'
);
```

## 최종 레이아웃 구조

```
┌─────────────────────────────────────────────┐
│ [position:fixed outer Box]                   │
│ top:0 / left:0 / right:0 / bottom:0         │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ AppBar (position:fixed, top:0)           │ │
│ │ height: 48px + var(--sat)               │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ 메시지 영역 (flex:1, overflow:auto)       │ │
│ │                                          │ │
│ │ [spacer flex:1]  ← 빈 공간              │ │
│ │ 메시지 1                                 │ │
│ │ 메시지 2                                 │ │
│ │ 최신 메시지  ← 항상 하단 근처            │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ 입력 영역 (flexShrink:0)                 │ │
│ │ pb: var(--effective-sab)                │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ [키보드 또는 홈 인디케이터]                   │
└─────────────────────────────────────────────┘
```
